### 1. Постановка задачи

#### Гит для поэта

Разработать программу для реализации системы контроля версий, предназначенной для работы со стихотворениями. Реализовать функционал добавления, удаления и изменения строк, сохранения состояний, отката к предыдущим версиям и сравнения изменений между ними.

#### Описание функционала

1. **Создание объекта гита** — создание объекта гита по названию стихотворения, автору и максимальному количеству сохраняемых версий.
2. **Вывод стихотворения (переопределение `toString`)** — отображение текущей версии стихотворения в формате `«НазваниеСтиха - ИмяПоэта»` и строки построчно.
3. **Добавление строки** — добавление новой строки в конец текущего стихотворения.
4. **Удаление строки по номеру** — удаление строки с указанным номером (нумерация начинается с `1`).
5. **Вставка строки по номеру** — вставка новой строки в указанное место со сдвигом последующих строк вниз.
6. **Сохранение версии** — сохранение текущей версии стихотворения. Если количество сохранений превышает максимум, самое старое сохранение удаляется *(массив строк копируется, а не передаётся по ссылке)*.
7. **Просмотр сохранений** — вывод сохранённой версии. Нумерация версий: `0` — текущая версия, `1` — последнее сохранение и так далее.
8. **Удаление сохранения** — удаление указанного сохранения. Более ранние сохранения, если были удалены, не восстанавливаются.
9. **Откат к сохранению** — откат текущей версии к указанному сохранению. При этом текущая версия и все более поздние сохранения стираются.
10. **Сравнение версий** — сравнение двух версий или текущей версии с одной из сохранённых:
    * если передана одна версия, она сравнивается с текущей;
    * если переданы две версии, они сравниваются между собой.
11. **Общие строки между версиями** — вывод строк, которые есть в обеих версиях, в порядке их появления в более новой версии.
12. **Различные строки между версиями** — вывод строк, которые встречаются только в одной из версий:
    * строки из старой версии, которых нет в новой, помечаются знаком `-` и выводятся в порядке их появления в старой версии;
    * строки из новой версии, которых нет в старой, помечаются знаком `+` и выводятся в порядке их появления в новой версии.


### 2. Описание класса

#### Поля класса `GitPoem`

| Название поля | Тип данных | Модификатор доступа | Что хранит |
| :--- | :--- | :---: | :--- |
| `name` | `String` | `private` | Название стихотворения |
| `author` | `String` | `private` | Имя автора |
| `savesLimit` | `int` | `private` | Лимит сохранений |
| `poem` | `String[]` | `private` | Массив строк текущей версии стихотворения |
| `saves` | `String[][]` | `private` | Двумерный массив для хранения сохранений |
| `savesCount` | `int` | `private` | Счётчик текущего количества сохранённых версий в массиве `saves` |

#### Конструктор класса `GitPoem`

Конструктор `public GitPoem(String name, String author, int savesLimit)` создает новый объект гита. При создании объекта сам текст стиха (массив строк) и список сохранений пусты (`poem` инициализируется как пустой массив `new String`, счётчик `savesCount` равен `0`, а под двумерный массив `saves` выделяется память под указанное максимальное количество версий).

| Параметр | Тип данных | Назначение |
| :--- | :--- | :--- |
| `name` | `String` | Название стихотворения |
| `author` | `String` | Имя автора (поэта) |
| `savesLimit` | `int` | Максимальное количество сохраняемых версий |

#### Методы класса `GitPoem`

| Метод | Модификатор | Параметры | Возвращаемое значение | Зачем нужен |
| :--- | :---: | :--- | :---: | :--- |
| `toString()` | `public` | — | `String` | Вывод текущей версии стихотворения |
| `addString(String s)` | `public` | `s` — новая строка | `void` | Добавляем одну строчку в конец стиха |
| `deleteString(int numString)` | `public` | `numString` — номер строки | `void` | Удаление строки по номеру |
| `insertString(String s, int numString)` | `public` | `s` — строка,<br>`numString` — позиция вставки | `void` | Вставка строки по номеру |
| `save()` | `public` | — | `void` | Создание сохранения |
| `printSave(int numSaved)` | `public` | `numSaved` — номер версии | `void` | Вывод сохранения |
| `deleteSave(int numSaved)` | `public` | `numSaved` — номер сохранения | `void` | Удаляет указанное сохранение |
| `returnVersion(int numSaved)` | `public` | `numSaved` — номер сохранения | `void` | Откат к указанному сохранению |
| `contains(String[] lines, String currString)` | `private static` | `lines` — массив строк,<br>`currString` — искомая строка | `boolean` | Вспомогательный метод: проверяет наличие строки в стихе |
| `compareVersions(int numSaved)` | `public` | `numSaved` — номер сохранения | `void` | Сравнение текущей версии с указанным сохранением |
| `compareVersions(int numSaved1, int numSaved2)` | `public` | `numSaved1`, `numSaved2` — номера сохранений | `void` | Сравнение указанных сохранений |


### 3. Тест

1. Создадим объект нашего гита - стих, добавим в него начальное кол-во строк (проверка методов `addString`, `toString`).

```java
// Создаем объект класса GitPoem - наш стих; лимит сохранений - 3
GitPoem poem = new GitPoem("Бородино", "М.Ю. Лермонтов", 3);

// Изначально строк в стихе нет
out.print(poem);
// Запишем строки нашего стиха (их 7)
String[] strings = {
        "– Скажи-ка, дядя, ведь недаром",
        "Москва, спалённая пожаром,",
        "Французу отдана?",
        "Ведь были ж схватки боевые,",
        "Да, говорят, ещё какие!",
        "Недаром помнит вся Россия",
        "Про день Бородина!"
};

for (int i = 0; i < 7; i++) {
    poem.addString(strings[i]);
}

// Выведем полученный стих
out.print(poem);
```
